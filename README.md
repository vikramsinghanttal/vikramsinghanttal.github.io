# vikramsinghanttal.github.io

Personal site for **Vikram Singh** — Staff Research Engineer at Tejas Networks, working on 3GPP RAN1/RAN2 standardization (ISAC, positioning, AI-RAN) and GPU-accelerated system simulation for 5G-Advanced/6G. Built with [Astro 5](https://astro.build) (content collections, static output) and [Tailwind v4](https://tailwindcss.com).

> Status: this repo is mid-migration from an earlier template (the original was built for a different person/domain). Several leftovers from that template are still in the code — they're called out explicitly in [Known gaps](#known-gaps) rather than hidden.
